# TTRPG Random Roller

A day/night event rolling tool for a personal TTRPG campaign. Built to practice SQLite3, vanilla JavaScript, Flask, and Pico CSS.

## Tech Stack

- HTML/CSS (Pico CSS framework)
- JavaScript (frontend logic)
- Flask
- SQLite3

## Features

- Roll random encounters for hours of the day
- Track hours of sunlight / hours til sunrise
- Night events coming soon

## How to Run Locally
   ```bash
   git clone https://github.com/tigosun-dev/personal-ttrpg-random-roller.git
   cd personal-ttrpg-random-roller
   python app.py

Open http://localhost:5000
